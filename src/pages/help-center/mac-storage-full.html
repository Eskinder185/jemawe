1. See what is using the space

  1. Open the Apple menu and choose System Settings.
  2. Select General > Storage.
  3. Wait for the bar to finish calculating. It shows categories such as Applications, Documents, Photos, and Messages.

On older versions of macOS, use Apple menu > About This Mac > Storage > Manage instead.

2. Use the recommendations

The Storage page offers options you can switch on:

  • Store in iCloud keeps older files and photos in iCloud and downloads them when needed. This uses your iCloud storage plan.
  • Optimize Storage removes TV shows and films you have already watched from the Mac.
  • Empty Trash Automatically deletes items that have been in the Trash for 30 days.

3. Clear large files and downloads

Select the information button next to Documents to sort files by size. The Downloads folder is often full of installers and duplicates you no longer need.

4. Remove old message attachments

Photos and videos sent in Messages can take many gigabytes. Select the information button next to Messages to review and delete large attachments.

5. Empty the Trash and restart

Deleted files still use space until the Trash is emptied. Empty it, then restart your Mac so macOS can clean up temporary files.

Back up before deleting

Before removing anything important, make sure you have a backup, for example with Time Machine on an external drive.

Still running out of space?

Many recent Macs cannot have internal storage upgraded. An external drive for archives and backups is usually the practical answer. Ask us if you are not sure what is safe to remove.
