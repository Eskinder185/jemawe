Check what you have

On Windows

  1. Open Task Manager with Ctrl + Shift + Esc and select Performance.
  2. Select Memory to see the total installed and how many slots are used.
  3. Select each Disk to see whether it is listed as SSD or HDD.

On a Mac

Open the Apple menu and choose About This Mac to see the chip and memory. Macs with Apple silicon chips have memory and storage built into the main board, so they cannot be upgraded later.

Signs you need more memory (RAM)

  • The computer slows down when several apps or many browser tabs are open.
  • Task Manager shows memory use close to 100 percent during normal work.

Signs you need faster storage (SSD)

  • Start-up takes minutes, and apps are slow to open even when little else is running.
  • The drive is listed as HDD, and disk activity sits near 100 percent.

When replacing makes more sense

  • Memory or storage is soldered to the board and cannot be changed.
  • The computer can no longer receive security updates for its operating system.
  • The repair or upgrade would cost a large share of a comparable new computer.
