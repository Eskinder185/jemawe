1. Turn off apps you do not need at start-up

Many programs set themselves to launch every time Windows starts. Each one slows sign-in a little.

  1. Press Ctrl + Shift + Esc to open Task Manager.
  2. Select Startup apps (in Windows 10, the Startup tab).
  3. Look at the Startup impact column. Select an app you do not need right away and choose Disable.

On Windows 11 you can also go to Settings > Apps > Startup and switch apps off there.

{{icon:info}}

Disabling a start-up app does not uninstall it. You can still open it normally. Leave security software and anything you do not recognize enabled until you have checked what it is.

2. Restart instead of shutting down

With Fast Startup turned on, Shut down saves part of the system state so the next boot is quicker. Over time that can carry problems forward. Restart performs a full fresh start, so use it when the computer feels sluggish, and after installing updates.

3. Free up storage space

Windows slows down when the system drive is nearly full.

  1. Open Settings > System > Storage.
  2. Review Temporary files and remove what you do not need.
  3. Turn on Storage Sense so Windows clears temporary files automatically.

4. Install pending updates

Open Settings > Windows Update (in Windows 10, Settings > Update & Security) and install what is waiting, then restart. Half-installed updates are a common cause of slow start-ups.

5. Run a security scan

Open Windows Security > Virus & threat protection and run a Quick scan. Unwanted software running in the background can slow everything down.

Still slow?

If the computer still takes a long time to start, it may have an older hard disk drive rather than a solid-state drive. Replacing it with an SSD is often the biggest single speed improvement. Read Is my computer worth upgrading? or request a support session.
