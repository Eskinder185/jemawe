1. Check other devices

If phones and other computers also lose the connection, the problem is likely the router or your internet service. If only one computer has trouble, start with that computer.

2. Restart the router and modem

  1. Unplug the modem and router from power.
  2. Wait 30 seconds.
  3. Plug in the modem first, wait until its lights settle, then plug in the router.

3. Forget the network and join again

  • Windows 11: Settings > Network & internet > Wi-Fi > Manage known networks, select the network, and choose Forget.
  • Mac: System Settings > Wi-Fi, select the information button next to the network, and choose Forget This Network.

Then reconnect and enter the Wi-Fi password.

4. Renew the connection on a Mac

In System Settings > Network > Wi-Fi, select Details next to your network, open TCP/IP, and choose Renew DHCP Lease.

5. Update the Wi-Fi driver on Windows

Install pending items in Windows Update, including optional driver updates. If you recently installed a driver and the trouble began afterwards, the manufacturer's support page may offer a more stable version.

6. Reset network settings (last resort)

On Windows 11, Settings > Network & internet > Advanced network settings > Network reset reinstalls network adapters and restores defaults. You will need to rejoin Wi-Fi networks and reinstall VPN software afterwards.

Signal matters

Thick walls, distance, and some appliances weaken Wi-Fi. If the connection is only bad in one room, try moving closer to the router to test.
