Upgrades we install

{{icon:memory}}

RAM

More memory for running several apps and browser tabs at once without slowdowns.

{{icon:drive}}

SSD

HDD

Large, affordable hard drives for desktop storage, archives, and backups.

Laptop batteries

A new battery when the old one drains quickly, will not hold a charge, or has swollen.

Will an upgrade help my computer?

{{icon:gauge}}Slow to start and open files

Usually storage. An SSD upgrade is often the fix.

{{icon:layers}}Slows down with many tabs or apps open

Usually memory. Adding RAM helps if your model supports it.

{{icon:battery}}Dies quickly off the charger

Usually the battery, which wears out with age and charge cycles.

{{icon:alert}}Some computers cannot be upgraded

Many thin laptops have memory and storage soldered to the board. We will tell you if that is the case before you spend anything.
