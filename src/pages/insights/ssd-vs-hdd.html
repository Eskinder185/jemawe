How they work

A hard disk drive (HDD) stores data on spinning magnetic platters read by a moving arm. A solid-state drive (SSD) stores data on flash memory chips with no moving parts.

Side by side

SSDHDD
SpeedMuch faster start-up, app launches, and file accessSlower, especially for many small files
DurabilityNo moving parts, so it copes better with knocksMoving parts can be damaged by drops
Noise and heatSilent, generally coolerAudible spinning and clicking, more heat
Cost per gigabyteHigherLower, especially at large sizes
Best forThe drive your system and apps run fromLarge archives and backup copies

Which should you choose?

  • For the main drive in any computer: an SSD. Replacing an old HDD with an SSD is often the single biggest speed improvement an older computer can get.
  • For bulk storage and backups: an HDD is still a cost-effective choice, especially as an external backup drive.

Not all SSDs connect the same way

SSDs come in different formats. Older laptops and desktops often use 2.5-inch SATA drives, while newer machines use small M.2 drives, many of which use the faster NVMe standard. The right one depends on what your computer supports, which is why we check the exact model before recommending a part.

One caution

Every drive eventually fails, SSD or HDD. When an SSD fails, recovering data from it can be harder than from an HDD. Whatever drive you have, keep a backup.
