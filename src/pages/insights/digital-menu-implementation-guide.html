1. Use a web page, not a PDF

A PDF menu is easy to make but hard to use: guests pinch and zoom, it loads slowly, screen readers struggle with it, and search engines may not read it well. A menu built as a web page adapts to the screen, loads quickly, and can be updated in place.

2. Organize by how guests decide

  • Group items into clear categories, such as starters, mains, drinks, and desserts.
  • Keep descriptions short: main ingredients and how it is prepared.
  • Show prices consistently, aligned so they are easy to scan.
  • Add dietary tags, such as vegetarian or vegan, and say how to ask about allergens.

3. Add photos carefully

Photos help, but large images slow the page on restaurant Wi-Fi. Use your own photos, sized for phones, and feature a few signature dishes rather than every item.

4. Make a QR code you never have to reprint

Point the QR code to a stable menu address on your own website. When the menu changes, the page changes, and every printed code still works. Print it large enough to scan easily from a seat, with the short web address written underneath for anyone who cannot scan. Test it with several phones before printing in bulk.

5. Keep it accessible

  • Readable text sizes and strong contrast, including in dim lighting.
  • Real text rather than images of text, so screen readers can read it.
  • Keep some printed menus available for guests who prefer them.

6. Decide how updates happen

Agree who changes the menu and how: editing it yourself through a simple form, or sending changes to whoever maintains the site. Plan seasonal and holiday menus ahead so they can be switched on the right day.

7. Check it from the guest's seat

Once it is live, scan the code at a table, on the restaurant's Wi-Fi and on mobile data. If it takes more than a few seconds to show the menu, it needs work.
