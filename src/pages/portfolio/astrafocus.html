What it is

AstraFocus is a browser-based workspace for planning tasks and protecting focus time. The live interface includes an overview, task list, calendar, projects, focus studio, priority matrix, goals, and analytics.

The problem it addresses

A long task list can make it hard to choose what matters next. The overview offers a next best action, a suggested time slot, and a direct way to start a focus session.

Visible product work

  • Task capture with priority and due-date options.
  • A next-action card with focus, detail, and scheduling controls.
  • Navigation between tasks, calendar, projects, matrix, goals, and focus tools, adapted for desktop and mobile.

Implementation choices

The public package identifies React, TypeScript, and Vite. The interface says the workspace is saved on the device, so the screenshots were made in fresh browser sessions with the fictional task “Review sample project plan.” No personal workspace data was opened or changed.

The visible next-action suggestion shows how the workspace connects planning with doing. It does not establish any measured productivity outcome.

What this project demonstrates

A task tool becomes more useful when a person can move from “what needs doing” to “when and how will I work on it.” AstraFocus puts capture, prioritization, scheduling, and a focus action close together while retaining a clear mobile navigation path.
