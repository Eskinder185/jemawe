What it is

CodeRush is a browser-based learning workspace for people practicing programming syntax, technical typing, Linux, PowerShell, networking, and defensive cybersecurity. Its public home page lets a visitor start a small Python typing exercise immediately.

The problem it addresses

Reading commands and understanding how to type and use them are different skills. CodeRush combines explanations, recall, and hands-on exercises so learners can practice the actual keystrokes and workflows.

Visible product work

  • A live code typing demo with line numbers, a cursor, accuracy and speed feedback, reset, and links to full practice.
  • Separate learning paths and navigation for lessons, skills lab, typing practice, command lab, and challenges.
  • A responsive interface that keeps the practice control usable on a phone.

Implementation choices

The public package identifies React, TypeScript, Vite, and Tailwind CSS. The home page exposes a short exercise before a learner chooses a path, giving visitors a concrete sense of the interaction. Local practice does not require an account.

What this project demonstrates

Educational software works best when the first useful action is close to the explanation. Here, visitors can understand the learning paths and try the core typing interaction on the same screen. The technical subject matter stays approachable through plain language and visible feedback.
