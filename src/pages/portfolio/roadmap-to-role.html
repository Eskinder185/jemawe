Overview

Roadmap to Role, also described in our portfolio as Professional Development for Fresh Graduates, is a career-development workspace for students and career changers. It combines self-assessments, résumé and LinkedIn preparation, interview practice, application tracking, and learning resources in one place.

The opportunity

New graduates are told to "build a portfolio" and "tailor every résumé" without a clear order to do it in. The aim was a structured path, Discover, Build, Grow, where each stage produces something a hiring team can actually review.

Objectives

  • Guide learners through choosing a direction before optimizing their profile.
  • Turn skills and projects into résumé lines, repositories, and interview stories.
  • Keep progress private by default, stored in the learner's own browser.

The solution

A React and TypeScript single-page application built with Vite and Tailwind CSS. Drafts and progress live in browser storage, and résumé parsing happens in the browser, so personal documents are not uploaded. An additive Java Spring Boot API with PostgreSQL and Flyway serves roadmap data, with authenticated local progress endpoints while production identity is deliberately deferred.

Features delivered

  • A Discover, Build, Grow pathway with career path blueprints and certification roadmaps.
  • Résumé tooling with keyword alignment for applicant tracking systems.
  • Portfolio, GitHub, and interview preparation that produces reviewable evidence.
  • Application tracking and learning resources.
  • Light and dark themes, and an in-app coaching panel.

Design and development decisions

  • Private by default. Browser storage with versioned migrations that preserve data and keep a recovery snapshot.
  • Quality gates in CI. Lint, type checks, unit tests, browser tests, and a production build run on every pull request.
  • Backend added without breaking the front end. The API is additive and read-only for catalog data.
