# Jemawe development instructions (for Cline, Claude, and other agents)

## Project
Jemawe is a technology solutions company website. Public pages only for now. Customer and staff portals are a later phase (see `docs/portal-architecture.md`).

## Environment
- Windows, PowerShell, VS Code
- Workspace: `C:\Users\eskew\github\jemawe`
- Local URL: `http://127.0.0.1:5500/` (`npm run serve`, or Live Server rooted at `dist/`)

## Architecture
- Source in `src/` (pages, partials, styles, ts, icons, site.json). Output in `dist/`, generated by `npm run build`. **Never hand-edit `dist/`.**
- Zero-dependency build (`scripts/build.mjs`). TypeScript compiled with `tsc`. No frameworks or Tailwind in this phase.
- The one exception is the home page 3D hero (`src/ts/hero3d/`): Three.js bundled by esbuild into `dist/js/hero3d.js`, lazy-loaded by `src/ts/eco-loader.ts`. Keep it progressive enhancement: the HTML service links and SVG fallback must keep working without it. See `docs/hero-3d.md`.
- Header, mega menu, mobile menu, breadcrumbs, and footer are generated from `src/site.json`. Change navigation there, not in pages.
- CSS tokens live in `src/styles/00-tokens.css`. Use them; do not hard-code colors or spacing.

## Rules
- Never access or modify `AstraFocusNexus` or other unrelated projects.
- Inspect files before modifying them. Keep changes small and focused.
- **Never invent** employees, names, titles, testimonials, ratings, statistics, certifications, prices, addresses, phone numbers, or company history. Use `{{todo "…"}}` for anything unconfirmed.
- **Never fake functionality.** Forms stay honest about not being connected until `formEndpoint` is set. Status pages show no data until real monitoring exists.
- Never collect passwords or payment card data in any form.
- Respect `prefers-reduced-motion`; content must be visible without JavaScript.
- Test with Playwright (`tests/qa_site.py`, and `tests/qa_eco.py` for the 3D hero). Report only results you actually observed.
- Use PowerShell-compatible commands.
- Do not introduce frameworks, commit, push, deploy, or connect production services without approval.
